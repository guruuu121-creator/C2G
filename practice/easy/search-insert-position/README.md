# Search Insert Position

## Difficulty: Easy

## Description
### Description
Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with $O(\log N)$ runtime complexity.

### Input Format
- The first line contains two integers: **N** (size of array) and **Target**.
- The second line contains **N** space-separated sorted distinct integers.

### Output Format
Print the index of the target or its insertion position.

### Constraints
* $1 \le N \le 10^4$
* $-10^4 \le \text{nums}[i], \text{Target} \le 10^4$

### Examples
**Example 1:**
Input:
\`\`\`
4 5
1 3 5 6
\`\`\`
Output:
\`\`\`
2
\`\`\`

**Example 2:**
Input:
\`\`\`
4 2
1 3 5 6
\`\`\`
Output:
\`\`\`
1
\`\`\`
