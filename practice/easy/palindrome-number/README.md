# Palindrome Number

## Difficulty: Easy

## Description
### Description
Given an integer **N**, write a program to check if it is a palindrome. An integer is a palindrome when it reads the same backward as forward.

### Input Format
A single integer **N**.

### Output Format
Print `true` if the integer is a palindrome, or `false` otherwise.

### Constraints
* $-2^{31} le N le 2^{31} - 1$

### Examples
**Example 1:**
Input:
```
121
```
Output:
```
true
```

**Example 2:**
Input:
```
-121
```
Output:
```
false
```
Explanation: From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome.
