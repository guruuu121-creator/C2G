# Fibonacci Number

## Difficulty: Easy

## Description
### Description
Write a program that takes an integer **N** and prints the N-th Fibonacci number.

The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones, starting from 0 and 1.
$$F(0) = 0, F(1) = 1$$
$$F(N) = F(N-1) + F(N-2) \\text{ for } N \\ge 2$$

### Input Format
A single integer **N**.

### Output Format
Print the N-th Fibonacci number.

### Constraints
* $0 \\le N \\le 30$

### Examples
**Example 1:**
Input:
```
2
```
Output:
```
1
```

**Example 2:**
Input:
```
5
```
Output:
```
5
```
