# Valid Perfect Square

## Difficulty: Easy

## Description
### Description
Given a positive integer **num**, write a program that returns `true` if **num** is a perfect square, or `false` otherwise.

Do not use any built-in library function such as `Math.sqrt()`.

### Input Format
A single positive integer **num**.

### Output Format
Print `true` if **num** is a perfect square, or `false` otherwise.

### Constraints
* $1 \le \text{num} \le 2^{31} - 1$

### Examples
**Example 1:**
Input:
\`\`\`
16
\`\`\`
Output:
\`\`\`
true
\`\`\`

**Example 2:**
Input:
\`\`\`
14
\`\`\`
Output:
\`\`\`
false
\`\`\`
