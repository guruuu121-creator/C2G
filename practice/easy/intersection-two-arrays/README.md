# Intersection of Two Arrays

## Difficulty: Easy

## Description
### Description
Given two integer arrays **nums1** and **nums2**, return an array of their intersection.

Each element in the result must be unique and you must output the result in sorted ascending order.

### Input Format
- The first line contains two integers: **N** (size of nums1) and **M** (size of nums2).
- The second line contains **N** space-separated integers representing **nums1**.
- The third line contains **M** space-separated integers representing **nums2**.

### Output Format
Print the unique elements of the intersection on a single line, space-separated, in ascending order. If the intersection is empty, print nothing.

### Constraints
* $1 \le N, M \le 1000$
* $0 \le \text{nums1}[i], \text{nums2}[i] \le 1000$

### Examples
**Example 1:**
Input:
\`\`\`
4 3
1 2 2 1
2 2 3
\`\`\`
Output:
\`\`\`
2
\`\`\`

**Example 2:**
Input:
\`\`\`
3 5
4 9 5
9 4 9 8 4
\`\`\`
Output:
\`\`\`
4 9
\`\`\`
