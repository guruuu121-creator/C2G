# First Unique Character in a String

## Difficulty: Easy

## Description
### Description
Given a string **s**, find the first non-repeating character in it and print its 0-based index. If it does not exist, print `-1`.

### Input Format
A single line containing the string **s**.

### Output Format
Print the index of the first unique character, or `-1` if all characters repeat.

### Constraints
* $1 \le \text{Length of s} \le 10^4$
* **s** consists of lowercase English letters.

### Examples
**Example 1:**
Input:
\`\`\`
leetcode
\`\`\`
Output:
\`\`\`
0
\`\`\`

**Example 2:**
Input:
\`\`\`
loveleetcode
\`\`\`
Output:
\`\`\`
2
\`\`\`
