# String Substring

## Difficulty: Easy

## Description
### Description
Write a Java program to extract a substring from a given string. The substring starts at index 1 and ends at index 3.

### Input Format
Line 1: A string S

### Output Format
The substring of S from index 1 to 3

### Constraints
1 <= length of S <= 100

### Examples
**Example 1:**
Input:
```
Hello
```
Output:
```
el
```
Explanation: The input string is 'Hello' and the substring from index 1 to 3 is 'el'.
