# Power of Two

## Difficulty: Easy

## Description
### Description
Given an integer **N**, write a program to check if it is a power of two.
An integer is a power of two if there exists an integer $x$ such that $N == 2^x$.

### Input Format
A single integer **N**.

### Output Format
Print `true` if **N** is a power of two, or `false` otherwise.

### Constraints
* $-2^{31} \le N \le 2^{31} - 1$

### Examples
**Example 1:**
Input:
\`\`\`
1
\`\`\`
Output:
\`\`\`
true
\`\`\`

**Example 2:**
Input:
\`\`\`
16
\`\`\`
Output:
\`\`\`
true
\`\`\`

**Example 3:**
Input:
\`\`\`
3
\`\`\`
Output:
\`\`\`
false
\`\`\`
