# String Reversal

## Difficulty: Easy

## Description
### Description
Write a Java program to reverse a given string.

### Input Format
Line 1: A string S

### Output Format
The reversed string

### Constraints
1 <= length of S <= 100

### Examples
**Example 1:**
Input:
```
Hello
```
Output:
```
olleH
```
Explanation: The input string is 'Hello' and its reverse is 'olleH'.
