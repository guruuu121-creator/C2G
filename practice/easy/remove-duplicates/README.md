# Remove Duplicates from Sorted Array

## Difficulty: Easy

## Description
### Description
Given a sorted integer array, remove the duplicate elements in-place such that each unique element appears only once.
Print the new length of the array, and on the next line, print the unique elements up to that length.

### Input Format
- The first line contains an integer **N** (the number of elements).
- The second line contains **N** space-separated sorted integers.

### Output Format
- Line 1: Print the new length **K**.
- Line 2: Print **K** space-separated unique elements.

### Constraints
* $1 \le N \le 1000$
* $-100 \le \text{nums}[i] \le 100$
* The input array is sorted in non-decreasing order.

### Examples
**Example 1:**
Input:
\`\`\`
3
1 1 2
\`\`\`
Output:
\`\`\`
2
1 2
\`\`\`
