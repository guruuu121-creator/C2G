# Defanging an IP Address

## Difficulty: Easy

## Description
### Description
Given a valid (IPv4) IP **address**, return a defanged version of that IP address.

A defanged IP address replaces every period `'.'` with `"[.]"`.

### Input Format
A single line containing the IP address string.

### Output Format
Print the defanged IP address.

### Constraints
* The input is a valid IPv4 address.

### Examples
**Example 1:**
Input:
\`\`\`
1.1.1.1
\`\`\`
Output:
\`\`\`
1[.]1[.]1[.]1
\`\`\`

**Example 2:**
Input:
\`\`\`
255.100.50.0
\`\`\`
Output:
\`\`\`
255[.]100[.]50[.]0
\`\`\`
