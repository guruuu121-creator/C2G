# Product of Array Except Self

## Difficulty: Medium

## Description
### Description
Given an integer array **nums** of length **N**, return an array **answer** such that **answer[i]** is equal to the product of all the elements of **nums** except **nums[i]**.

You must write an algorithm that runs in $O(N)$ time and without using the division operation.

### Input Format
- The first line contains an integer **N** (size of the array).
- The second line contains **N** space-separated integers.

### Output Format
Print the products space-separated on a single line.

### Constraints
* $2 \le N \le 5000$
* $-30 \le \text{nums}[i] \le 30$
* The product of any prefix or suffix of **nums** is guaranteed to fit in a 32-bit integer.

### Examples
**Example 1:**
Input:
\`\`\`
4
1 2 3 4
\`\`\`
Output:
\`\`\`
24 12 8 6
\`\`\`

**Example 2:**
Input:
\`\`\`
5
-1 1 0 -3 3
\`\`\`
Output:
\`\`\`
0 0 9 0 0
\`\`\`
