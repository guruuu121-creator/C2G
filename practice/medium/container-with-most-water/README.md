# Container With Most Water

## Difficulty: Medium

## Description
### Description
You are given an integer array **height** of length **N**. There are **N** vertical lines drawn such that the two endpoints of the $i$-th line are $(i, 0)$ and $(i, \text{height}[i])$.

Find two lines that together with the x-axis form a container, such that the container contains the most water.
Return the maximum amount of water a container can store.

### Input Format
- The first line contains an integer **N** (number of elements).
- The second line contains **N** space-separated integers representing array **height**.

### Output Format
Print a single integer representing the maximum volume of water that can be trapped.

### Constraints
* $2 \le N \le 10^4$
* $0 \le \text{height}[i] \le 10^4$

### Examples
**Example 1:**
Input:
\`\`\`
9
1 8 6 2 5 4 8 3 7
\`\`\`
Output:
\`\`\`
49
\`\`\`
Explanation: The vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water the container can contain is 49 (between index 1 and index 8).
